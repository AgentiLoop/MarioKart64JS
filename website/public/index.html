MK64JS

Mario Kart 64, rebuilt from scratch in JavaScript by AI agents, supervised by the AgentiLoop Team. The low-res graphics and sound are extracted from a Mario Kart 64 (USA) ROM, using the n64decomp/mk64 decompilation as the map. Hi-res graphics come from MK64 Reloaded (press G), and Wii-style 3D karts are a keypress away (press 3). The game code is a port of the decompiled original, running natively in Three.js, WebGL and Vita.

What's in the box

An experiment in how far AI-assisted development can go at re-creating a classic. Here's what works today.

All 16 courses

Every Mario Kart 64 track is rebuilt from course geometry and textures extracted from the ROM and verified against it, laid out by the n64decomp/mk64 decompilation.

The real soundtrack

A port of the decomp's sequence player decodes the VADPCM instruments and plays the original .m64 sequences in an AudioWorklet: title, menus and every course theme.

Kart physics

Karts ride the course surface in the track's frame and can't pass through walls. Ramps and crests send you airborne with the decomp's gravity and drag.

Drift & mini-turbo

Hold Space to power-slide, release for a mini-turbo. Exhaust smoke puffs are ported from the original particle code.

Items & roulette

Item boxes spawn where the original game puts them. Hit one and the item window spins through shells, bananas, mushrooms and the rest, at the original timing.

Wii 3D karts

Press 3 for 3D Wii-style karts and Lakitu with real shadows, a 3D title screen and 3D finish fly-overs, in place of the N64 sprites. Press 3 again to go back.

240p or HD

Play at an N64-style 240 lines, or 2×, 4× and native resolution with optional HD textures from the MK64 Reloaded pack. Press G to cycle.

Wii 3D karts: press 3

An alternative look, and yes, you can dig it. Hit 3 on the title screen and the N64 title becomes a 3D scene: Mario, Wario, Bowser, Peach and Toad in Wii-style Standard Karts driving at you down a scrolling road. Hit 3 again for the original art. In a race, 3 swaps every kart (each driver in their own Standard Kart) and the referee Lakitu for 3D models with real shadows. Your choice is remembered for the next race.

Download

Desktop builds of the latest release, all with the same 240p / 480p / 960p / native resolutions as the browser version, and all race online in 2P-4P GAME. Windows and Linux wrap the game in Electron. The macOS build uses the system WebKit instead (84 MB, not 305 MB) and is signed and notarized. The Raspberry Pi build is a small webview app on the system WebKitGTK.

Run it from source

You need Node.js.

git clone https://github.com/AgentiLoop/MarioKart64JS.git
cd MarioKart64JS
npm install
npm run dev        # http://localhost:5173

Hi-res graphics (press G) come from the MK64 Reloaded pack.
